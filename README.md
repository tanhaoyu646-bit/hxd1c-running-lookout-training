本仓库由验收后的“平稳起车与贯通试验”项目完整复制后独立建立。原项目不在本仓库内，当前修改不会写回原项目。

## 在线体验

- 途中瞭望训练：[打开 GitHub Pages](https://tanhaoyu646-bit.github.io/hxd1c-running-lookout-training/lookout-training/)
- 手机端建议横屏使用；页面已适配安全区、触控手柄、步骤面板和视角切换。

## 主考核入口

- `/lookout-training/`：途中瞭望技巧综合考评。
- `/continuity-test/`：冻结基线中保留的原贯通试验页面，用于回归比对。
- `/`：项目首页，首要入口指向途中瞭望考评。

## 固定流程与计分

总分100分，场景不随机：

1. 站内平稳发车（4分）与第一闭塞分区贯通试验（16分）。
2. 正常道口鸣笛通过（10分）。
3. 隧道出口轮廓异常处置及停车后坡道起车（20分）。
4. 钢轨反光/光带中断处置及停车后坡道起车（20分）。
5. 人员或车辆侵限道口处置及停车后坡道起车（30分）。
6. 完成场景后继续运行至结算点，自动弹出成绩单。

课堂版采用约6 km的压缩考核走廊：贯通试验阶段在1.75 km结束，正常道口位于2.2 km，短隧道位于3.2–3.5 km，钢轨光带中断边界位于4.6 km，侵限道口位于5.6 km。途中在1.8、2.8、3.8、4.8和5.8 km各设一架绿灯通过信号机，编号依次为2328、2316、2302、2288、2274。地形高程和地表纹理来自原NEIYI线路，道口、隧道和信号机复用原线路素材。

## 当前三维基线

- 瞭望项目单独加载8 m原生高程，不改动贯通试验页使用的原地形文件。
- 主线保留原场景的侧线、接触网和周边资产；车辆运行线使用连续实体钢轨头与三维轨枕，不再使用平面高亮条假充钢轨。
- 本务主线依据原NEIYI TrackDB中心线在页面加载时一次性生成到完整约38.3 km路径终点，不随列车运行临时生成，也不再在6 km考核终点附近截断。
- 近景由真实尺寸的立体轨身和接近原线路加载画面的中灰金属轨头显示，不使用白色底色或自发光；150–310 m后渐入的屏幕空间远景LOD使用同一钢色和稳定的最小屏幕宽度，避免在深色地形中变黑消失。相机远裁剪面覆盖完整线路路径，LOD不覆盖反光中断段。
- 地形只在本线路基周边做限高和渐变，24 m外保持原线路高程。
- 短隧道由3段100 m原游戏洞壁模型和原洞门组成，摆放时保留坡度姿态。出口外20 m设置塌方，通过晴天洞口过曝和暗色剪影呈现轮廓异常。
- 钢轨反光在4.6 km危险边界处突然中断，后续180 m保持暗哑；实体钢轨和列车运行线不中断。
- 侵限道口轿车按真实时间从左向右循环横穿，不会因学生停车而停止动画。

普通异常场景动作顺序为“鸣笛→自阀紧急位→牵引主手柄零位→危险点前停车→停车后单阀全制位”。侵限道口在牵引退零后增加第二次独立鸣笛。停车后的坡道起车顺序为“查询尾部风压→缓解单阀→牵引主手柄1.0级→缓解自阀→再次查询尾部风压”。任一异常场景未在危险点前停车，该场景整体记0分，但列车继续进入后续考核。
