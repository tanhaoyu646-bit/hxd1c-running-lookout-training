# HXD1C途中瞭望技巧虚拟仿真

本仓库由验收后的“平稳起车与贯通试验”项目完整复制后独立建立。原项目不在本仓库内，当前修改不会写回原项目。

## 主考核入口

- `/lookout-training/`：途中瞭望技巧综合考评。
- `/continuity-test/`：冻结基线中保留的原贯通试验页面，用于回归比对。
- `/`：项目首页，首要入口指向途中瞭望考评。

## 固定流程与计分

总分100分，场景不随机：

1. 站内平稳发车（4分）与第一闭塞分区贯通试验（16分）。
2. 正常道口（5分）：鸣笛3分，不实施无必要紧急制动2分。
3. 隧道出口轮廓异常（25分）。
4. 钢轨反光/光带中断（25分）。
5. 人员或车辆侵限道口（25分）。
6. 完成场景后继续运行至结算点，自动弹出成绩单。

普通异常场景动作顺序为“鸣笛→自阀紧急位→牵引主手柄零位→危险点前停车→停车后单阀全制位”。侵限道口在牵引退零后增加第二次独立鸣笛。任一异常场景未在危险点前停车，该场景整体记0分，但列车继续进入后续考核。

## 本地运行与校验

```powershell
python -m http.server 4175
npm run check
```

访问 `http://127.0.0.1:4175/lookout-training/`。三维资源通过 `fetch` 加载，不能直接双击 HTML 文件运行。
