# 旅客列车操纵提示卡与贯通试验

这是从既有平稳起车技术基座复制后独立维护的 H5 项目。当前仓库的修改不会写回原平稳起车项目。

## 页面结构

- `/`：默认进入铁路运行曲线拼接训练（操纵提示卡）。教学区段显示为“爱国站—敬业站”，两端仅为站标，不显示灯色。
- `/continuity-test/`：进入“平稳起车＋贯通试验”综合考评。默认平道、默认考评模式，普通错误只扣分不拦截；设备物理联锁仍按实际状态生效。
- 综合考评内只启用平道起车条件，不向考生提供上坡道选择。

## 当前考评规则

- 总分100分：平稳起车20分，贯通试验80分。
- 贯通试验步骤：确认尾部风压600 kPa；58～62 km/h时自阀置初制动位；随后按住单阀手柄向右侧滑动并持续保持；排风、速度下降后由6.0级退至5.0级；打开LKJ观察；缓解自阀；恢复至6.0级及以上。
- 侧缓单缓不是独立按钮：只在自阀初制动评分项正确完成后接受单阀右滑保持证据，松手自动回到原位。提前操作不计入该评分项。
- LKJ保留“株洲站”既有参数，第一闭塞分区教学限速线为120 km/h。
- 牵引主手柄6.0级本质上仍表示牵引力级位，不是现场机车的速度定速器；本教学项目另行标定为60 km/h开始削减牵引、64 km/h硬上限。贯通试验以58～62 km/h作为初制动评分窗口，越过窗口不拦截，只扣分。
- 贯通试验页面不提供绿色许可证、路票和非正常行车入口。

## 信号与曲线页面

- 默认四显示自动闭塞，灯色随拼接进度逐段生成，不预先显示整条区间；后方信号按红、黄、绿黄、绿变化。
- K222+603为出站信号机；2328、2316、2302、2288、2274为通过信号机；K226+091为进站信号机。
- 灯色绘制在各信号机标识圆圈内；爱国站、敬业站不绘制信号灯。
- 每轮三个运行线选项互不重复，并尽量避开最近两轮已出现的图片。
- 红色限速线采用操纵示意图中的红线，页面支持手机横屏自适应。受浏览器限制，自动锁定横屏仅能在用户点击进入后尝试执行；不支持时显示旋转提示。

## 显示与区间资源

- LKJ窗口按可用宽度和高度同时缩放，桌面端和手机横屏均保留完整物理键区。
- 三维区间路线长度约38.3 km；第一闭塞分区后段（8～10 km）已纳入资源密度校验。跨长距离实例关闭组级视锥裁剪，避免远端场景被整组误隐藏；驾驶视点使用真实轨道构件朝向生成的连续中心线，避免曲线段在线性插值时切弦离轨。

## 本地运行与校验

```powershell
python -m http.server 4175
npm run check
```

访问：

- 操纵提示卡：`http://127.0.0.1:4175/`
- 贯通试验：`http://127.0.0.1:4175/continuity-test/`

三维资源通过 `fetch` 加载，不能直接双击 HTML 文件运行。
